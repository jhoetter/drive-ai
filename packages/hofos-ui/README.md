# @driveai/hofos-ui

Built hofOS UI surface for DriveAI. Consume it from a GitHub Release tarball:

```json
"@driveai/hofos-ui": "https://github.com/jhoetter/drive-ai/releases/download/v0.1.0/driveai-ui-0.1.0.tgz"
```

Run `pnpm --filter @driveai/hofos-ui build:dist` to produce the library-mode `dist/` artifact.
